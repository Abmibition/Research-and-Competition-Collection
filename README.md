## 三、按项目看

上面的奖项并非彼此孤立，主要由三条项目线产出：

### 项目一：便携式仿生嗅觉肉类新鲜度检测系统（CH32V307）

多传感器气体阵列 + 端侧神经网络推理的猪肉新鲜度检测装置，是本人投入最久、链条最完整的一条线，
从原型机做到了竞赛、专利与公开数据集：

- 🥇 CIMC「西门子杯」全国总决赛 **一等奖**（华北一赛区初赛特等奖晋级）
- 🥉 全国大学生嵌入式芯片与系统设计竞赛全国总决赛三等奖（北部赛区一等奖晋级）
- 📄 发明专利 202610953507.1，已公开并进入实质审查
- 📊 配套数据集 [Pork-enose-dataset](https://github.com/Abmibition/Pork-enose-dataset) 已按 CC BY 4.0 开源

### 项目二：智疗雷诺 —— 雷诺病智能中医电疗系统

- 🎓 国家级大学生创新创业训练计划项目，2026-06 结项合格
- 📄 论文《雷诺病智能中医电疗系统设计》被《当代电力文化》录用（2025 年第 22 期）

### 项目三：机器人与智能车竞赛线

面向机器人任务赛、仿真与智能车的持续参赛积累，覆盖机械结构、运动控制、导航与仿真：

- 中国高校智能机器人创意大赛：省选拔赛一等奖 → 全国二等奖
- CRAIC 系列：人工智能创新赛（省一 → 国一）、机器人任务挑战赛、机器人舞蹈赛
- 吉林省高校大学生机器人大赛 搬运机器人任务赛一等奖
- 吉林省大学生智能汽车竞赛、工程实践与创新能力大赛（智能网联汽车省特等奖）
